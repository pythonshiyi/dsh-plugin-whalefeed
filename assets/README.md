# 鲸鱼娘自定义形象素材规范

把生成好的图片放到本目录，然后告诉我文件名即可。我会把它们接入插件，替换掉当前内置的 SVG 占位形象。

## 推荐方案：5 张阶段立绘 + 表情差分

### 必需：5 张阶段立绘（同一角色、同一姿势、同一画布）

| 文件名 | 肚子状态 |
| --- | --- |
| `stage-0.png` | 平坦小腹 / 鲸鱼苗 |
| `stage-1.png` | 小腹微微凸起 |
| `stage-2.png` | 肚子圆润鼓起 |
| `stage-3.png` | 肚子明显变大 |
| `stage-4.png` | 肚子巨大圆滚 / 巨鲸神 |

要求：

- 透明背景 PNG
- 统一尺寸（推荐 1024×1024 或 512×512）
- 同一角色、同一姿势、同一光源、同一画风
- 只有肚子大小变化，其他部分尽量一致
- 不要文字、不要水印、不要对话框

### 建议：表情差分（可选，但强烈推荐）

| 文件名 | 表情 |
| --- | --- |
| `face-eating.png` | 张嘴开心进食，可拿小鱼 |
| `face-happy.png` | 星星眼 / 非常开心 |
| `face-sleepy.png` | 犯困 / 打哈欠 |
| `face-shy.png` | 脸红害羞 |
| `face-thinking.png` | 托腮思考 |

如果难以保证一致性，最少给我：

- `face-eating.png`
- `face-happy.png`
- `face-sleepy.png`

### 可选：装饰差分

如果立绘没有包含装饰，也可以提供：

- `accessory-stage2.png`：珍珠 / 蝴蝶结
- `accessory-stage3.png`：小皇冠
- `accessory-stage4.png`：光环 / 鲸鱼神气息

### 可选：精灵序列帧（用于动画）

如果会做 Sprite Sheet，推荐使用 Codex 桌宠契约：

- 8 列 × 9 行
- 每格 192×208
- 透明背景
- 9 种动作：空闲、向右跑、向左跑、挥手、跳跃、失败、等待、奔跑、审查

我可以直接把它接入动画系统。

## 保持角色一致的小技巧

- 使用同一张参考图 / 同一个 Seed / 同一 LoRA
- 先生成一张“基准立绘”，后续所有图都基于它 img2img / 参考生图
- 如果 AI 生成后角色细节漂移，优先保证“脸和发型一致”，肚子大小是主要变化点
- 导出时选择“透明背景 PNG”，不要 JPG
